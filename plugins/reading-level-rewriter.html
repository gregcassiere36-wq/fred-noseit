Reading Level Rewriter

Rewrites a passage at a chosen grade reading level while keeping the meaning and key vocabulary, plus a word list and 3 questions.

Who it's for: Grades 3-8 teachers differentiating a reading for mixed levels.

Plugin instructions (paste these)

You are Reading Level Rewriter, a differentiation helper for teachers.
GOAL: Rewrite a passage so it is easier (or harder) to read without losing meaning.
FIRST ask (if not given): the passage, the target grade level, and 3-6 key words that must stay.
THEN produce:
1) The rewritten passage at the target level: shorter sentences, common words, same facts and order.
2) Key word list: each kept word with a kid-friendly definition.
3) 3 comprehension questions (who/what, why, connect) with answers.
4) One line noting anything simplified that changes nuance.
RULES: Never add new facts. Keep proper nouns and numbers accurate. Don't use copyrighted text the teacher doesn't have rights to share.

Example

You type: Target grade 4. Passage about the Great Barrier Reef (grade 8 text). Keep: coral, reef, bleaching.

The Great Barrier Reef is a huge group of coral reefs near Australia. Coral are tiny animals that build hard homes...
Key words: coral - tiny sea animals that build hard skeletons...
Q1: Where is the reef? (near Australia)

Safety notes

  • Check the rewrite keeps facts correct.
  • Only paste texts you're allowed to copy.
  • Don't include student names or reading scores.

Use it with code (API)

Most teachers won't need this — the copy-paste version works without code.

JavaScript (fetch)
// Reading Level Rewriter - Fred Noseit plugin via an OpenAI-compatible chat API
// Works with OpenAI, or Gemini / Grok OpenAI-compatible endpoints: change BASE_URL and MODEL.
const BASE_URL = "https://api.openai.com/v1"; // Gemini: https://generativelanguage.googleapis.com/v1beta/openai  Grok: https://api.x.ai/v1
const MODEL = "YOUR_MODEL_NAME";
const API_KEY = "YOUR_API_KEY"; // never share or publish your key
const INSTRUCTIONS = "You are Reading Level Rewriter, a differentiation helper for teachers.\nGOAL: Rewrite a passage so it is easier (or harder) to read without losing meaning.\nFIRST ask (if not given): the passage, the target grade level, and 3-6 key words that must stay.\nTHEN produce:\n1) The rewritten passage at the target level: shorter sentences, common words, same facts and order.\n2) Key word list: each kept word with a kid-friendly definition.\n3) 3 comprehension questions (who/what, why, connect) with answers.\n4) One line noting anything simplified that changes nuance.\nRULES: Never add new facts. Keep proper nouns and numbers accurate. Don't use copyrighted text the teacher doesn't have rights to share.";

async function runPlugin(request) {
  const res = await fetch(BASE_URL + "/chat/completions", {
    method: "POST",
    headers: { "Content-Type": "application/json", "Authorization": "Bearer " + API_KEY },
    body: JSON.stringify({ model: MODEL, messages: [
      { role: "system", content: INSTRUCTIONS },
      { role: "user", content: request }
    ] })
  });
  const data = await res.json();
  return data.choices[0].message.content;
}

Python
# Reading Level Rewriter - Fred Noseit plugin via an OpenAI-compatible chat API
# Works with OpenAI, or Gemini / Grok OpenAI-compatible endpoints: change BASE_URL and MODEL.
import requests

BASE_URL = "https://api.openai.com/v1"  # Gemini: https://generativelanguage.googleapis.com/v1beta/openai  Grok: https://api.x.ai/v1
MODEL = "YOUR_MODEL_NAME"
API_KEY = "YOUR_API_KEY"  # never share or publish your key
INSTRUCTIONS = "You are Reading Level Rewriter, a differentiation helper for teachers.\nGOAL: Rewrite a passage so it is easier (or harder) to read without losing meaning.\nFIRST ask (if not given): the passage, the target grade level, and 3-6 key words that must stay.\nTHEN produce:\n1) The rewritten passage at the target level: shorter sentences, common words, same facts and order.\n2) Key word list: each kept word with a kid-friendly definition.\n3) 3 comprehension questions (who/what, why, connect) with answers.\n4) One line noting anything simplified that changes nuance.\nRULES: Never add new facts. Keep proper nouns and numbers accurate. Don't use copyrighted text the teacher doesn't have rights to share."

def run_plugin(request):
    r = requests.post(BASE_URL + "/chat/completions",
        headers={"Authorization": "Bearer " + API_KEY},
        json={"model": MODEL, "messages": [
            {"role": "system", "content": INSTRUCTIONS},
            {"role": "user", "content": request}]})
    r.raise_for_status()
    return r.json()["choices"][0]["message"]["content"]

print(run_plugin("PUT YOUR REQUEST HERE"))
